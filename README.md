# dart-knx

KNX libraries from [Busclear](https://busclear.de), open for everyone (BSD 3-Clause).

| Package | Language | What |
|---|---|---|
| [`knx`](packages/knx) | Dart (VM, Flutter, web) | Addresses, cEMI, KNXnet/IP headers, datapoint types, DPT guessing, KNX Secure |
| [`knx_io`](packages/knx_io) | Dart (VM) | Bus connections: KNXnet/IP tunnel (UDP, TCP, IP Secure), routing, FT1.2/kBerry |
| [`kberry`](python/kberry) | Python | FT1.2 and cEMI for the Weinzierl kBerry and similar serial modules |

The FT1.2 implementations in Dart and Python test against the same vectors in
[`test-vectors/ft12.json`](test-vectors/ft12.json) (generated by
`packages/knx_io/tool/make_vectors.dart`).

## Develop

```sh
dart pub get
(cd packages/knx && dart test) && (cd packages/knx_io && dart test)
cd python/kberry && pip install -e '.[test]' && pytest
```
